# Sonic 2 MD+ Forge v3.0.1

Release date: 2026-10-04.

Version 3.0.1 freezes the selective Bugfixed audio-data and level-data work
merged after v3.0.0, including PR #45's asset-boundary remediation. Production
remains the default, byte-identical to its hardware-qualified Stage 5/v2/v3
image. Bugfixed retains isolated outputs and its own strict identity and layout.

This release contains tooling, configuration and documentation only. It does
not distribute Sonic 2 ROMs, Sega game assets, upstream source/assets, Addryu
audio, converted soundtrack files, disc images or generated MiSTer packages.
Users supply their own lawfully obtained soundtrack files for local builds.

## Why a patch release

Semantic Versioning applies to Forge's tooling/public interface. Since v3.0.0,
no public command/API has been removed or incompatibly changed, and no new
public feature requires a minor-version bump. Curated Bugfixed corrections,
verification/evidence work and repository-policy cleanup therefore warrant
v3.0.1. The breaking legacy-interface retirement remains part of the historical
[v3.0.0 release](v3.0.0.md).

Package metadata in `pyproject.toml` and runtime `__version__` in
`tools/mdplus_builder/__init__.py` are synchronised to `3.0.1`. The shared
`--bugfixed` help now describes curated game and data corrections; it no longer
claims byte identity with Production. Command names, flags, defaults and
behaviour are unchanged by release preparation.

## Source and build architecture

All four maintained ROMs use `sonicretro/s2disasm` REV01 at immutable commit
`380f37a731bfc720bb0371a35a593184a7ec5e43` in `config/dependencies.json`.
The dependency pin is unchanged. Ignored `build/source-modern/` remains a
read-only input; preparation clones committed input into disposable trees.
Upstream Lua/native tools assemble and finalize the ROM; no finished-ROM patch
is applied.

| Role | Source policy | Output |
| --- | --- | --- |
| Stock Production | Untouched pinned REV01 | `build/sonic2-stock-modern.md` |
| Production MD+ | Pristine retail policy plus Forge | `build/sonic2-mdplus.md` |
| Stock Bugfixed | Curated game/data policy, no Forge | `build/sonic2-stock-bugfixed.md` |
| Bugfixed MD+ | Curated game/data policy plus Forge | `build/sonic2-mdplus-bugfixed.md` |

Bugfixed reuses authoritative `bugfixed.apply_policy()`, validates all eight
post-policy source/object hashes, then applies the shared Forge adapter. The
adapter does not reconstruct or extend the policy. Stock Bugfixed retains its
independent strict verifier and exclusion audit. Neither stock reference has a
package command.

Production preparation, names and compatibility aliases remain unchanged.
`build/sonic2-modern-mdplus.md` remains a relative symlink to
`sonic2-mdplus.md`, selecting only Production. Both prepared trees, ROMs and
package directories coexist; reserved output paths preserve isolation.

## Selective Bugfixed corrections

The frozen curated gameplay policy, including downstream MCZ drill, Obj2B and
Obj82 collision corrections, remains intact. The [Bugfixed policy](../BUGFIXED.md)
retains the complete technical scope, hashes and historical evidence.

### Audio data

Only these corrections are selected through the authoritative policy:

- Spin Dash Release FM5 transpose correction.
- Credits PSG2 pitch/transposition correction.
- Neutralisation of the obsolete Credits compensation, preserving its width
  and every existing sound-data address.

`FixMusicAndSFXDataBugs=0` remains enforced globally, including the separate
compressed-song environment in `build.lua`. Sky Chase and Death Egg music-data
changes and global music/SFX fixes remain excluded. `FixDriverBugs=0` remains
in force; no upstream Z80 driver fixes are adopted. Native driver overflow
already masks the malformed Spin Dash transpose, so the source/compiled audit
establishes the correction without claiming a new audible effect.

### Level objects

Only these hash-checked pinned Fixed Files semantics are selected:

| Layout | Selected corrections |
| --- | --- |
| EHZ2 | Cave/high rolling-jump wall, wall/spring floor-clip guard, lower-corridor pathswapper |
| ARZ2 | Progression pathswapper only; existing bubble generator deliberately retained |
| WFZ1 | Diagonal conveyor correction |

EHZ2 uses the current pinned reference with the issue-#111 ordering/capsule
regression absent; retail signpost/capsule entries remain unchanged. ARZ2 is a
selective derivation from retail, deliberately differing from the full reference
that removes its bubble generator. WFZ1 changes only the conveyor subtype.

All other Fixed Files remain excluded: ARZ2 bubble-generator removal, CPZ1/CPZ2
and DEZ1 door replacements, OOZ2 push-spring changes, HTZ/MTZ object cleanup,
ring-data cleanup and every other substitution. The complete alternate 2P
sprite mechanism remains excluded with `ForgeFix2PSpritePageFlip=0`.

### Asset-boundary remediation

PR #45 review identified exact six-byte Sega level-object records copied into
Forge source, tests and documentation by the initial implementation. The merged
implementation removes those payloads. Forge retains only operation/index/count
semantic shapes and hashes; actual object payloads are derived from the
hash-checked pinned dependency at build/audit time. Independent reconstruction
uses separately checked dependency slices and does not import the production
transformation. Synthetic unit fixtures do not vendor Sega records.

The remediation leaves every maintained ROM identity unchanged. Release
verification audits the current tracked files and new release record for known
object payloads derived from the pinned input, and checks for generated payload
files. This records the current repository state; it does not rewrite Git
history or claim that unreachable GitHub objects from the pre-amend PR never
existed.

## Layout and integration invariants

The selective level changes add 24 uncompressed object bytes, absorbed by
existing alignment before `SoundDriverLoad=$ED000`. Each Bugfixed ROM differs
from its exact pre-level baseline in 17,041 bytes, fully accounted for by the
header checksum, moved relative object pointers and selected/shifted object
entries, boundaries and shorter zero padding. All 25 changed symbol values
are accounted for; no code, sound, Z80, bank-target or RAM symbols move.
Independent reversal reconstructs both complete pre-level ROMs exactly.

Production Forge remains at `$100000`; Bugfixed Forge remains at
`$108000-$1086BF`, exclusive end `$1086C0`, after sound end `$107FEC`.
Each layout's hooks, loader, compressed/loaded driver and eight complete Z80
bank-switch expansions retain independent audits. Z80 implementation, MD+
routing and track policy are unchanged.

Both variants preserve the `$FFF100-$FFF5FF` RAM hole and Forge allocations.
They retain exactly 21 adjacent open/write/close MD+ transactions, 42 control
signatures and 21 command signatures. Overlay activation remains after Sonic's
startup checksum; a failed checksum never opens it. Checksum, MD+ signatures,
PCM format and sector-alignment requirements are not weakened.

## Deferred work and observations

CPZ/DEZ doors remain research-only. All nine Fixed Files replacements use
subtype `$02`, not `$03`; the existing two runtime stores forcing `$03` are a
workaround. Proper adoption would likely require all nine replacements and
retirement of both stores, with broader address/layout movement and its own
complete software/hardware audit. None is included in v3.0.1.

OOZ2 Obj45 push springs remain deferred. The `$30 -> $02` corrections materially
alter behaviour and require dedicated hardware investigation before adoption.
Z80 driver fixes, global music/SFX fixes and Sky Chase/Death Egg audio-data work
also remain deferred/excluded. No selected or excluded policy changes occur
during release preparation.

[Issue #26](https://github.com/lloydsmart/sonic2-mdplus-forge/issues/26), the
intermittent Special Stage results text corruption, remains an open observation.
This release does not claim to fix it or establish its cause.
